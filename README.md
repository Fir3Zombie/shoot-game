As of current time the game consists of movement and moving the direction your character faces, this will be updated as time goes on and it should end up looking more like a rouge like top down zombie shooter game, where you can buy guns and ammo to help you survive, stronger and harder waves of enemies.

You will use basic movement keys, consisting of W, A, S, D (W = move forward, S = move backward, A = move to the left, D = move to the right)
Your character will be constantly looking at your cursor, This means that when shooting will be added you will be able to shoot where your mouse is.
The mud (brown blobs on the map) will lower your character speed.

The game is currently a work in progress so the game you will get isn’t the finish copy at the moment. (this will be edited when the full game as been completed)
I coded this game using the software Godot and it. And all sprites (character designs) were made using Krita.
